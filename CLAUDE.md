## Principios atómicos

### 1. Claude no aparece en el repositorio

- **PROHIBIDO** firmar commits como Claude o como co-autor (`Co-Authored-By: Claude`).
- **PROHIBIDO** dejar atribuciones, marcas o referencias a Claude / Anthropic en mensajes de commit, PRs, código, comentarios, README, documentación o cualquier artefacto versionado.
- **PROHIBIDO** ejecutar `git commit` o `git push` con autor distinto al del usuario humano dueño del repo.
- **Razón**: la rúbrica del proyecto evalúa los commits **individuales** de cada estudiante. Cualquier rastro de Claude perjudica la evaluación.
- **Aplicación**: cualquier acción de git (commit, amend, PR, tag, mensaje) la propone Claude pero la ejecuta el usuario, o se ejecuta con el autor humano configurado localmente y sin trailers automáticos.
