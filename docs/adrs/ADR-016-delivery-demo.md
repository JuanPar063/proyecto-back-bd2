# ADR-016 — Demo end-to-end como criterio de cierre

## Estado

Adoptado

## Contexto

El Entregable 2 requiere demostrar el flujo completo del sistema.

## Decisión

La entrega se cerrará con una demo end-to-end:
profesor crea reto, estudiante envía query, worker evalúa, IA recomienda y reportes muestran resultados.

## Consecuencias

- Obliga a integrar todos los módulos.
- Facilita validar errores antes de grabar el video final.
